How This Site Was Made

Tools We Used

I wrote the project’s HTML code in Visual Studio Code and used the Live Server extension so I could open my website in the browser while I was working on it. This is very convenient because you can see changes immediately without having to refresh the page. I wrote the code, created each file, and checked to see if they worked and opened in the browser. After I finished working on each page, I checked it using the W3C Markup Validator to make sure there were no errors in the HTML and that my code followed the required structure.

How I Started Each Page

Every page starts with the same basic structure, which I typed using the Emmet shortcut ! and then pressing Tab. 

<!DOCTYPE html>
<html lang="en">
<head>
    ...
</head>

Checking My Work

I validated every page using the W3C Markup Validator. A page with no errors shows this message:

Document checking completed. No errors or warnings to show.

My Experience Creating the Website

I decided to choose Noble as the theme for my website because it’s a very popular and beautiful place. I wanted to make the website stand out—not like typical cafes or clothing stores, but a truly unique place. I wanted to create a simple website like this so that customers could learn about the store, browse the products, and find the information they need.

I created a project with a basic HTML structure for all the pages. First, I created the home page, which contains basic information about Noble and includes photos; then I created the second page, which describes the product categories and prices; and I created the page with all the store’s contact information.Finally, I created this Colophon page to explain how I made the website.

In this project, one of the most challenging parts for me was the HTML semantic elements. It wasn't easy for me to incorporate them into the code so that they weren't just for show but actually served a purpose—I had to really dig into it. Creating tables and linking form fields also required careful attention.

To sum it up, I’ve learned a lot. For example, I learned to write HTML code in a more structured way and to use semantic elements. I discovered this beautiful tableware store. I realized how convenient it is to write code using an extension. I also learned how to properly test code and understood the importance of keeping code organized.
