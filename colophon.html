Noble — Tableware Store

About the Project

Tools We Used

Noble is a student website about a tableware store in Astana. HTML provides the page structure, Bootstrap 5.3.3 handles responsive layouts and navigation, and shared CSS applies the Noble colours and fonts. The team keeps the source files and change history in GitHub.

How Pages Are Structured

Each page has a document type, language, head, and body. In an editor with Emmet enabled, the shortcut ! followed by Tab can generate this starting structure. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>About the Project | Noble</title>
</head>
<body>
    <main>
        <h1>About the Project</h1>
    </main>
</body>
</html>

Checking the Website
