# Noble — Tableware Store Website

Project for the "Introduction to Web Technologies" course (Assignment 1: HTML Basics).
Author: Utembayeva Karakat, SE-2535 

## About the project

The site is dedicated to a real tableware store chain, **Noble**, in Astana. The site
is built entirely with plain HTML — no CSS and no JavaScript, as required by the assignment.

## File structure

```
noble-project/
├── indexx.html         — home page (about the store + photos)
├── page-1.html          — product catalog: price table, categories, top 3
├── page2.html           — contact page with a form
├── colophon.html         — how the site was made
├── images/               — photos of the store and products
├── tag_checklist(2).md       — checklist of tags used
├── AI_log(1).md              — AI usage log
└── README.md
```

## How to open

Open `indexx.html` in any browser (double-click), or use the Live Server extension
in VS Code for auto-refresh while editing. Navigation between pages works through
the `<nav>` on every page.

## Tools

- **Visual Studio Code** — writing the code
- **Live Server** (VS Code extension) — browser preview
- **W3C Markup Validator** (validator.w3.org) — HTML validity check; all 4 pages pass with zero errors
- **Git** — version control, 6 commits across 3 different days

## Real data

All data in the project is real: Noble's address, opening hours, and phone number,
product prices (collected in person / by calling the store), 3+ photographs taken
personally by the author, and an employee quote (Aigerim) recorded with a name and date.
